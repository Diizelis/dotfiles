# Mani Dotfiles (LXC CLI Vide)

Šis repozitorijs satur konfigurāciju manai modernajai termināļa darba videi uz Ubuntu 25.04 LXC konteinerā.

### Izmantotie rīki un bāze:
- **OS:** Ubuntu 25.04 (1 vCPU, 2GB RAM)
- **Shell:** Zsh ar Oh My Zsh un Powerlevel10k motīvu
- **Spraudņi:** zsh-autosuggestions, zsh-syntax-highlighting
- **Editor:** Neovim (ar manis izvēlēto konfigurāciju/ietvaru)
- **CLI rīki:** `eza` (moderns ls), `bat` (moderns cat), `fzf` (fuzzy finder), `zoxide` (viedais cd).

### Uzstādīšana
Lai lietotu šos failus, nepieciešams uzstādīt attiecīgos rīkus un nokopēt konfigurācijas uz `~/.zshrc` un `~/.config/nvim`.
